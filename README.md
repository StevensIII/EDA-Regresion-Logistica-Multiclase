# Clasificación Multiclase: Evaluación de Autos

Este proyecto tiene como objetivo analizar un conjunto de datos del dominio automotor para resolver un problema de **clasificación multiclase**, usando diversos algoritmos de Machine Learning.

📌 **Dataset utilizado:**  
[Car Evaluation Data Set - UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/19/car+evaluation)

## 🔍 Objetivos

- Describir y explorar el conjunto de datos.
- Seleccionar las variables más relevantes.
- Dividir los datos en conjunto de entrenamiento y prueba.
- Aplicar y comparar modelos de clasificación:
  - Perceptrón
  - Regresión Logística
  - Un tercer algoritmo investigado por fuera del curso

## 🛠️ Herramientas usadas

- Python (Jupyter Notebook)
- Scikit-learn
- Pandas, NumPy, Matplotlib, Seaborn

## 📊 Evaluación de modelos

- Matriz de confusión
- Accuracy
- Otro índice adicional investigado

## 📁 Archivos

- `EDA-Regresion-Logistica-Multiclase.ipynb`: Desarrollo completo del análisis.
- `car.data`: Dataset original.
